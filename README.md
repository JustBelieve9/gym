# Тренировка

Помощник в зале на двоих: программа по дням, отметка подходов, прогресс дня и таймер отдыха.
Статическая страница без сборки и без зависимостей.

**Открыть:** https://justbelieve9.github.io/gym/

## Программы

**Костя** — верх-низ, акцент на грудь и спину. 68 подходов в неделю.

| День | Фокус | Подходов |
|---|---|---|
| Понедельник | Верх A · акцент грудь | 20 |
| Среда | Низ + плечи | 23 |
| Пятница | Верх B · акцент спина | 25 |

**Маша** — низ-верх-низ, акцент на ягодицы. 36 подходов в неделю, только база,
отдых 2–3 минуты на компаундах.

| День | Фокус | Подходов |
|---|---|---|
| Понедельник | Низ A · задняя цепь | 12 |
| Среда | Верх | 12 |
| Пятница | Низ B · квадрицепс | 12 |

Обоснование объёмов и ссылки на исследования — во вкладке «Справка», она своя у каждого.

## Как пользоваться

- Переключатель вверху слева выбирает, чья программа. Отметки у каждого свои.
- Кнопка справа переключает светлую и тёмную тему. Первый заход берёт тему из системных настроек.
- Нужный день выбирается сам по дню недели, вкладки листаются пальцем или стрелками.
- Тап по кружку отмечает подход и сразу запускает таймер отдыха.
- Отметки хранятся в браузере и переживают перезагрузку. На следующий день день очищается сам.
- Экран не гаснет, пока страница открыта.

## Как править программу

Всё лежит в [`data.js`](data.js) — остальные файлы трогать не нужно.

```js
{ name: "Хип-траст со штангой", sets: 4, reps: "8–12", rest: 120, superset: null }
```

| Поле | Значение |
|---|---|
| `name` | название упражнения |
| `sets` | число рабочих подходов |
| `reps` | диапазон повторов |
| `rest` | отдых после подхода в секундах; `0` — сразу вторая часть суперсета |
| `superset` | общая метка у упражнений одной связки, иначе `null` |

Соседние упражнения с одинаковым `superset` объединяются скобкой.
Подписи на переключателе — это `PEOPLE.k.label` и `PEOPLE.a.label` в том же файле.
Изменил число подходов — отметки текущего дня сбросятся сами, чтобы не разъехались.

## Рабочие веса

Один вес на упражнение. Тап по чипу под карточкой раскрывает поле, `Enter` или потеря фокуса
фиксируют значение, `Escape` отменяет. Принимаются и точка, и запятая.

Хранится всё в браузере, **база данных не нужна**:

| Ключ `localStorage` | Содержимое |
|---|---|
| `gym-<кто>-<день>` | `{ date, sets, weights, startedAt, sent }` — сбрасывается на следующий день |
| `gym-<кто>-lastw` | `{ "<название упражнения>": вес }` — переживает сброс, подставляется подсказкой |
| `gym-theme`, `gym-sound`, `gym-person` | настройки |

`lastw` ключуется **названием упражнения, а не номером** — перестановка программы в `data.js`
не перепутает веса между упражнениями.

## Звук окончания отдыха

iOS усыпляет Web Audio, как только экран гаснет или браузер уходит в фон, поэтому звук защищён
тремя слоями: беззвучный медиа-луп держит аудиосессию живой, тон планируется в аудиографе заранее
и переживает торможение JS, Media Session помечает страницу как играющую медиа.
Колокольчик в шапке выключает звук — вибрация при этом остаётся.

**Предел:** при нажатой кнопке блокировки iOS всё равно может усыпить звук. Надёжнее всего
не блокировать телефон — Wake Lock и так не даёт экрану гаснуть, пока страница открыта.

## Отчёт в телеграм

Когда закрыта последняя галочка дня, отчёт с упражнениями и весами уходит в личку.
Есть и ручная кнопка. Подключение — ссылка «Подключить телеграм» в «Справке», по одной на каждого.

Токен бота **нельзя** класть в репозиторий, поэтому между сайтом и Telegram стоит
Cloudflare Worker `gym-report` (папка `worker/`) — он хранит токен в секретах, а `chat_id` в KV.
Данные тренировок он не хранит.

```bash
cd worker && npx wrangler secret put TG_TOKEN   # значение вводится в приглашении
```

Затем один раз открыть `https://gym-report.thezavarkin.workers.dev/setup`, чтобы Worker
прописал себе вебхук. Проверка живости — `/health`.

**Про безопасность честно:** URL Worker виден в клиентском JS. Проверка `Origin` и суточный лимит —
защита от случайного шума, **а не аутентификация**. Худшее, что может сделать посторонний, —
прислать мусор в личку; доступа к боту или к данным при этом нет.

## Файлы

| Файл | Назначение |
|---|---|
| `index.html` | разметка и содержимое вкладки «Справка» |
| `styles.css` | токены обеих тем и вёрстка |
| `app.js` | выбор человека и темы, рендер, отметки, прогресс, таймер, хранилище |
| `data.js` | программы тренировок |
| `worker/` | Cloudflare Worker для отчётов в телеграм. Секретов в файлах нет |

Цветовые токены обеих тем проверены по WCAG: весь текст проходит уровень AA,
границы контролов — минимум 3:1.

## Кеш при обновлении

GitHub Pages отдаёт файлы с `Cache-Control: max-age=600`. Чтобы новый `index.html` никогда не
подхватил старый `app.js`, ссылки на ассеты помечены версией: `styles.css?v=5`, `data.js?v=5`,
`app.js?v=5`. **Правишь эти файлы — увеличь номер версии во всех трёх ссылках в `index.html`.**
Правки только внутри `data.js` без смены версии подтянутся сами в течение 10 минут.
