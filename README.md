# Тренировка

Помощник в зале на двоих: программа по дням, отметка подходов, прогресс дня и таймер отдыха.
Статическая страница без сборки и без зависимостей.

**Открыть:** https://justbelieve9.github.io/gym/

## Программы

**Костя** — верх-низ, акцент на грудь и спину. 68 подходов в неделю.

| День | Фокус | Подходов |
|---|---|---|
| Понедельник | Верх A · акцент грудь | 20 |
| Среда | Низ + плечи | 23 |
| Пятница | Верх B · акцент спина | 25 |

**Маша** — низ-верх-низ, акцент на ягодицы. 36 подходов в неделю, только база,
отдых 2–3 минуты на компаундах.

| День | Фокус | Подходов |
|---|---|---|
| Понедельник | Низ A · задняя цепь | 12 |
| Среда | Верх | 12 |
| Пятница | Низ B · квадрицепс | 12 |

Обоснование объёмов и ссылки на исследования — во вкладке «Справка», она своя у каждого.

## Как пользоваться

- Переключатель вверху слева выбирает, чья программа. Отметки у каждого свои.
- Кнопка справа переключает светлую и тёмную тему. Первый заход берёт тему из системных настроек.
- Нужный день выбирается сам по дню недели, вкладки листаются пальцем или стрелками.
- Тап по кружку отмечает подход и сразу запускает таймер отдыха.
- Отметки хранятся в браузере и переживают перезагрузку. На следующий день день очищается сам.
- Экран не гаснет, пока страница открыта.

## Как править программу

Всё лежит в [`data.js`](data.js) — остальные файлы трогать не нужно.

```js
{ name: "Хип-траст со штангой", sets: 4, reps: "8–12", rest: 120, superset: null }
```

| Поле | Значение |
|---|---|
| `name` | название упражнения |
| `sets` | число рабочих подходов |
| `reps` | диапазон повторов |
| `rest` | отдых после подхода в секундах; `0` — сразу вторая часть суперсета |
| `superset` | общая метка у упражнений одной связки, иначе `null` |

Соседние упражнения с одинаковым `superset` объединяются скобкой.
Подписи на переключателе — это `PEOPLE.k.label` и `PEOPLE.a.label` в том же файле.
Изменил число подходов — отметки текущего дня сбросятся сами, чтобы не разъехались.

## Файлы

| Файл | Назначение |
|---|---|
| `index.html` | разметка и содержимое вкладки «Справка» |
| `styles.css` | токены обеих тем и вёрстка |
| `app.js` | выбор человека и темы, рендер, отметки, прогресс, таймер, хранилище |
| `data.js` | программы тренировок |

Цветовые токены обеих тем проверены по WCAG: весь текст проходит уровень AA,
границы контролов — минимум 3:1.
