# Тренировка

Помощник в зале: три дня в неделю, отметка подходов, прогресс дня и таймер отдыха.
Статическая страница без сборки и без зависимостей.

**Открыть:** https://justbelieve9.github.io/gym/

## Программа

| День | Фокус | Подходов |
|---|---|---|
| Понедельник | Верх A · акцент грудь | 20 |
| Среда | Низ + плечи | 23 |
| Пятница | Верх B · акцент спина | 25 |

Целевой объём — 10–12 фракционных подходов на мышцу в неделю (прямой подход считается за 1,
косвенный за 0,5). Обоснование и источники — во вкладке «Справка».

## Как пользоваться

- Нужный день выбирается сам по дню недели, вкладки переключаются пальцем или стрелками.
- Тап по кружку отмечает подход и сразу запускает таймер отдыха.
- Отметки хранятся в браузере и переживают перезагрузку. На следующий день день очищается сам.
- Экран не гаснет, пока страница открыта.

## Как править программу

Всё лежит в [`data.js`](data.js) — остальные файлы трогать не нужно.

```js
{ name: "Жим гантелей на наклонной 30°", sets: 3, reps: "6–10", rest: 150, superset: null }
```

| Поле | Значение |
|---|---|
| `name` | название упражнения |
| `sets` | число рабочих подходов |
| `reps` | диапазон повторов |
| `rest` | отдых после подхода в секундах; `0` — сразу вторая часть суперсета |
| `superset` | общая метка у упражнений одной связки, иначе `null` |

Соседние упражнения с одинаковым `superset` объединяются скобкой. Изменил число подходов —
отметки текущего дня сбросятся сами, чтобы не разъехались.

## Файлы

| Файл | Назначение |
|---|---|
| `index.html` | разметка и содержимое вкладки «Справка» |
| `styles.css` | токены темы и вёрстка |
| `app.js` | рендер, отметки, прогресс, таймер, хранилище |
| `data.js` | программа тренировок |

