# Тренировка

Помощник в зале на двоих: программа по дням, отметка подходов, вес и повторы по подходам,
прогресс дня и таймер отдыха с пингом в телеграм.
Статическая страница без сборки и без зависимостей.

**Открыть:** https://justbelieve9.github.io/gym/

## Программы

**Костя** — верх-низ, акцент на грудь и спину. 66 подходов в неделю.

| День | Фокус | Подходов |
|---|---|---|
| Понедельник | Верх A · акцент грудь | 20 |
| Среда | Низ + плечи | 21 |
| Пятница | Верх B · акцент спина | 25 |

**Маша** — низ-верх-низ, акцент на ягодицы. 36 подходов в неделю, только база,
отдых 2–3 минуты на компаундах.

| День | Фокус | Подходов |
|---|---|---|
| Понедельник | Низ A · задняя цепь | 12 |
| Среда | Верх | 12 |
| Пятница | Низ B · квадрицепс | 12 |

Обоснование объёмов и ссылки на исследования — во вкладке «Справка», она своя у каждого.

## Как пользоваться

- Переключатель вверху слева выбирает, чья программа. Отметки у каждого свои.
- Кнопка справа переключает светлую и тёмную тему. Первый заход берёт тему из системных настроек.
- Нужный день выбирается сам по дню недели, вкладки листаются пальцем или стрелками.
- Тап по кружку отмечает подход и сразу запускает таймер отдыха.
- В каждой строке подхода — поля веса и повторов. Плейсхолдер подставляется с прошлой тренировки.
- У упражнения с альтернативами под названием есть чипы: тап делает вариант активным на этот день.
- Отметки, веса и выбор альтернатив хранятся в браузере и переживают перезагрузку. На следующий день день очищается сам.
- Экран не гаснет, пока страница открыта.

## Как править программу

Всё лежит в [`data.js`](data.js) — остальные файлы трогать не нужно.

```js
{ name: "Хип-траст со штангой", sets: 4, reps: "8–12", rest: 120, superset: null,
  alts: ["Хип-траст в тренажёре", "Ягодичный мост с гантелью"] }
```

| Поле | Значение |
|---|---|
| `name` | основное упражнение |
| `alts` | массив альтернатив (то же движение / та же мышца); можно опустить |
| `sets` | число рабочих подходов |
| `reps` | диапазон повторов |
| `rest` | отдых после подхода в секундах; `0` — сразу вторая часть суперсета |
| `superset` | общая метка у упражнений одной связки, иначе `null` |

`alts` появляются в приложении чипами под названием — тап переключает активное упражнение дня.
Вес и повторы у каждого варианта свои (`lastw` ключуется названием).

Соседние упражнения с одинаковым `superset` объединяются скобкой.
Подписи на переключателе — это `PEOPLE.k.label` и `PEOPLE.a.label` в том же файле.
Изменил число подходов — отметки текущего дня сбросятся сами, чтобы не разъехались.

## Вес и повторы по подходам

В каждой строке подхода два поля: вес и повторы. `change` (потеря фокуса или `Enter`) фиксирует
значение, принимаются и точка, и запятая. Пустой плейсхолдер берётся с прошлой тренировки этого
упражнения, дальше по сессии подхватывается уже введённое.

Хранится всё в браузере, **база данных не нужна**:

| Ключ `localStorage` | Содержимое |
|---|---|
| `gym-<кто>-<день>` | `{ date, sets, log, pick, startedAt, sent }` — сбрасывается на следующий день |
| `gym-<кто>-lastw` | `{ "<название>": { w, r } }` — переживает сброс, подставляется подсказкой |
| `gym-theme`, `gym-person`, `gym-lastTab` | настройки |

`log[i][j]` — это `{ w, r }` для `j`-го подхода `i`-го упражнения. `pick[i]` — выбранная
альтернатива (или `null` = основное). `lastw` ключуется **названием упражнения, а не номером** —
перестановка программы и переключение альтернативы не путают подсказки. Старые записи
(`weights` — один вес на упражнение) читаются: вес уходит в первый подход.

## Таймер отдыха и пинг в телеграм

Таймер отдыха — визуальный обратный отсчёт на плашке внизу. Звука нет.

Сигнал об окончании приходит пингом в телеграм. Сайт при старте отдыха шлёт `POST /timer`
(`{ person, seconds, label }`), Worker кладёт задачу в Durable Object `RestTimer`
(`state.storage.setAlarm`). По `alarm()` DO берёт `chat_id` из KV и отправляет «⏱️ Отдых окончен».
Планирование на стороне Cloudflare, поэтому пинг доходит, даже когда телефон заблокирован и
вкладка усыплена — то, чего не давал звук.

`+30`, «заново» — переставляют alarm; «пропустить», закрытие плашки и естественное догорание
таймера на активном экране шлют `POST /timer/cancel`, чтобы не пришёл дубль. Без подключённого
телеграма `/timer` отвечает `409`, приложение это молча проглатывает — визуальный таймер работает.

## Отчёт в телеграм

Когда закрыта последняя галочка дня, отчёт с упражнениями, весами и повторами по подходам уходит
в личку. Есть и ручная кнопка. Подключение — ссылка «Подключить телеграм» в «Справке», по одной
на каждого.

Токен бота **нельзя** класть в репозиторий, поэтому между сайтом и Telegram стоит
Cloudflare Worker `gym-report` (папка `worker/`) — он хранит токен в секретах, `chat_id` в KV,
а таймеры отдыха в Durable Object. Данные тренировок он не хранит.

```bash
cd worker && npx wrangler secret put TG_TOKEN   # значение вводится в приглашении
cd worker && npx wrangler deploy                # миграция Durable Object применится сама
```

Затем один раз открыть `https://gym-report.thezavarkin.workers.dev/setup`, чтобы Worker
прописал себе вебхук (после добавления таймера переустанавливать вебхук не нужно —
маршруты Telegram не менялись). Проверка живости — `/health` (в ответе есть `timerBinding`).

**Про безопасность честно:** URL Worker виден в клиентском JS. Проверка `Origin` и суточный лимит —
защита от случайного шума, **а не аутентификация**. Худшее, что может сделать посторонний, —
прислать мусор в личку; доступа к боту или к данным при этом нет.

## Файлы

| Файл | Назначение |
|---|---|
| `index.html` | разметка и содержимое вкладки «Справка» |
| `styles.css` | токены обеих тем и вёрстка |
| `app.js` | выбор человека и темы, рендер, альтернативы, отметки, вес/повторы, прогресс, таймер, хранилище |
| `data.js` | программы тренировок |
| `worker/` | Cloudflare Worker: отчёты в телеграм + `RestTimer` (Durable Object) для пинга таймера. Секретов в файлах нет |

Цветовые токены обеих тем проверены по WCAG: весь текст проходит уровень AA,
границы контролов — минимум 3:1.

## Кеш при обновлении

GitHub Pages отдаёт файлы с `Cache-Control: max-age=600`. Чтобы новый `index.html` никогда не
подхватил старый `app.js`, ссылки на ассеты помечены версией: `styles.css?v=7`, `data.js?v=7`,
`app.js?v=7`. **Правишь эти файлы — увеличь номер версии во всех трёх ссылках в `index.html`.**
Правки только внутри `data.js` без смены версии подтянутся сами в течение 10 минут.
